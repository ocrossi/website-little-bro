TRANSLATIONS (js/translations.js)
═══════════════════════════════════════════════
- URL strategy: /, /fr/, /en/, /es/
- Detection order: 1) URL prefix → 2) localStorage("lang") → 3) navigator.language → 4) "fr"
- All translatable text uses data-i18n="key.subkey" attributes
- For attributes: data-i18n-attr="placeholder:key,title:key2"
- Translation object structure:
    { fr: { nav:{...}, hero:{...}, prestations:{...}, ... }, en: {...}, es: {...} }
- EN/ES: provide REAL translations ONLY for:
    nav links, CTA buttons, section headings, hero quote, form labels, footer
- Card descriptions, bios, legal text in EN/ES = "Translation coming soon"
- On lang change: update html[lang], URL via pushState, localStorage, re-render all [data-i18n]
- Update <meta description> and document.title per language
